Guide to using AI tools effectively in your development workflow.

## Tool Overview

| Feature | CodeCompanion | Supermaven | Database AI |
|---------|---------------|-----------|-------------|
| **Type** | Chat + Inline | Completion | SQL-specific |
| **API** | Google Gemini | Proprietary | Built-in miudb |
| **Strength** | Complex problems | Real-time coding | SQL queries |
| **Best For** | Architecture, debugging | Day-to-day coding | Database work |
| **Keybindings** | Leader-based | Auto-trigger | Context-aware |

## Codex CLI

Codex is managed from this dotfiles repo through GNU Stow. See **[Codex](/ai/codex/)** for the repo-owned `~/.codex/config.toml`, enabled features, `/goal` troubleshooting, MCP setup, and plugin checks.

## Grok CLI

Grok is managed the same way. See **[Grok](/ai/grok/)** for the repo-owned `~/.grok/config.toml`, native hooks, Claude/Cursor compatibility, and MCP setup.

## oh-my-dsh

oh-my-dsh shares the official DeepSeek Harness document at `~/.dsh/settings.yaml`. See **[oh-my-dsh](/ai/omdsh/)** for the managed DeepSeek default, the pi-style `cliproxyapi` gateway, and Z.AI Coding.

## pi

pi's user settings (`~/.pi/agent/settings.json`) are stowed from this repo, including the extension list. See **[pi](/ai/pi/)** for package restore on a fresh machine and Langfuse tracing via the official `pi-langfuse` extension.

## Quick Start

```bash
# CodeCompanion (Chat with Gemini)
<leader>ac  # Open AI chat
<leader>aa  # AI actions menu
<leader>ar  # Code review
<leader>af  # Quick fixes

# Supermaven (Completion - auto-triggers)
# Just start typing, suggestions appear automatically
# Tab to accept, Ctrl+] to dismiss
```
